Закрыты находки проверки безопасности.

- `core`, `doctor`: полная память повторов отказывает (`503 replay_memory_full`), а не вытесняет старые метки; метку команды управления занимает только запрос, прошедший проверку роли; на `/v1/control/*` — не больше 60 запросов в минуту с адреса (`429`).
- `doctor`: общий секрет, секрет владельца и секрет моста — попарно разные и не короче 32 знаков; проверяют `check-config` и старт врача.
- `paseo-bridge`: агент подписывает команды ключом задачи из письма, секрет моста ему не нужен. **Ломающее:** `remontnik-paseo` требует `--key`. Тип отчёта — внутри блока данных. Заголовки проверяются до тела, есть пределы соединений и время на заголовки.
- `browser`: пока на странице вписан пароль, запросы и WebSocket на сайты вне `allowedOrigins` закрыты (`refused_leak`); живой экран принимает `POST` только со своей страницы.
