- **Случай, закончившийся без излечения, можно лечить заново.** Раньше `case <id> retry` отвечал `409 case_finished` на `report_only`, `no_cause_found`, `stand_broken`, `needs_human` и `not_helped`. Новый случай по тому же сбою тоже не открывался: повтор клеился к старому. Так случай, кончившийся «только отчётом» из-за поломки самого набора (в верстаке не было pnpm), оставался без лечения навсегда. Теперь команда начинает новую попытку: своя копия и ветка `-rN`, потолок случая `diagnoseUsdPerCase` заново. Дневные потолки, пределы автовыкаток и пометка «нужен человек» после отката прежние. `case_finished` — только для закрытых случаев (`healed`, `healed_by_paseo`, `rolled_back`).
- **Сам врач такой случай второй раз не лечит.** Повторы сбоя по-прежнему клеятся к открытому случаю: круга «сбой → отчёт → тот же сбой → снова лечить» без человека нет.
- **Отчёт говорит, как повторить.** Отчёты итогов без излечения (кроме «правка готова») кончаются строкой `Лечить заново: remontnik-doctor case <номер> retry` — и в Telegram, и в ленте для Paseo.
- **Повтор задачи, остановленной, пока случай у агента Paseo**, (`handoff_check`, `handed_off`, `paseo_working`, `reclaimed`) больше не получает ложный `case_finished`: остановленная задача продолжается, живая — `already_running`.

### Как обновить приложение

1. Обновить врача: на сервере перевести клон Ремонтника на метку новой версии и пересобрать (`docker compose -f deploy/compose.remontnik.yml up -d --build`). Настройку приложения менять не нужно.
2. Найти номера случаев, которые кончились без излечения и ещё не вылечены: последний отчёт случая — `cause_found`, `no_cause_found`, `stand_broken`, `needs_human` или `not_helped` (лента отчётов или Telegram).
3. Если причина неудачи ушла (например, случай кончился «только отчётом» из-за pnpm в верстаке до 0.1.7), поставить случай в работу снова:

   ```bash
   docker compose -f deploy/compose.remontnik.yml exec doctor remontnik-doctor case <номер> retry --by owner
   ```

   Ответ `{"caseId":<номер>,"retried":"restarted","attempt":2}` — новая попытка началась. `409 already_running` — лечение уже идёт, `409 case_finished` — случай закрыт.
