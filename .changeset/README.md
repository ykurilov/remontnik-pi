# Changesets

Все пакеты `@ykurilov/remontnik-*` выходят одной версией (группа `fixed`).

После любой правки пакета: `pnpm changeset` — выбрать пакеты, тип правки и написать, что изменилось.
Пока версия `0.x`: `minor` — новая возможность или ломающее изменение, `patch` — исправление.

Как выходит версия — в [RELEASING.md](../RELEASING.md).
