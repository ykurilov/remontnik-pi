# Контракт: что делает приложение при подключении

Подключение делает агент приложения по `docs/getting-started.md`. Ремонтник код приложения не правит. Список ниже — то, что приложение обязано дать.

1. **Сторож в коде**: `createWatch` при старте каждого процесса; `installProcessHandlers()`; хуки `/agent-chat`, если стоит Agent Chat SDK; `conversationFinished` в месте, где разговор закрывается; `watch.flush` при штатной остановке.
2. **Файл `remontnik.config.ts`** в корне, с запретными зонами, закрытыми путями, картой eval и командами.
3. **Команды выкатки** по [deploy-commands.md](./deploy-commands.md): `build` из указанной папки, `promote` с сохранением прежней сборки, `rollback` без git, `current` с версией, `health`. Общий файл-замок с ручной выкаткой.
4. **Команда eval** с выбором сценариев, потолком денег и итогом в формате контракта; отдельные ключи моделей для eval с маленьким лимитом; отдельная база для прогонов.
5. **Службы для тестов** (если тестам нужна база) — файл compose, который врач может поднять отдельно от боевых (`checks.services`). Врач поднимает его в сети проверок случая без портов, томов и секретов; разрешённые поля — в [remontnik-config.md](./remontnik-config.md#службы-для-тестов-checksservices). Тесты ходят к базе по имени службы.
6. **Окружение сервера**: общий секрет сторожа и врача, ключ git врача, ключи моделей Ремонтника, токен бота тревог, ключи браузера — по `secret-handoff`, только в окружении сервера.
7. **Правила GitHub** из `deploy/github-ruleset.json`.
8. **Учётка Ремонтника** в кабинете приложения и сохранённый вход в браузере (отдельная учётка с минимальными правами — решение Юрия).
9. **Конституция и правила приложения** не должны запрещать автоматическую выкатку врачом (решение Юрия: для Генератора лидмагнитов правила поправляет агент приложения).
10. **Стоп-кран в Telegram** — врач ставит кнопку «Остановить автовыкатку» (`callback_data: "remontnik:stop"`) под отчётами о готовой правке, выкатке, откате и «не помогла»; при включённом стоп-кране кнопки нет, а в тексте сказано, что он включён. Бот тревог — приложения, поэтому нажатие получает приложение и отдаёт `watch.handleStopButton(callbackQuery)`. Сторож проверяет, что нажали в чате тревог, шлёт врачу `POST /v1/control/deploys` `{ action: "stop" }`, подписанный общим секретом, и возвращает текст для `answerCallbackQuery`; `null` — кнопка не сторожа. Не бросает. Пуска (`resume`) кнопкой нет: только командой с секретом владельца.
11. **По желанию — режим «сначала Paseo»** по [paseo-bridge.md](./paseo-bridge.md): частная сеть между сервером и компьютером владельца, мост Paseo с назначенным агентом приложения, секрет моста в окружении сервера и в настройке моста. Правила выкатки приложения для агента Paseo — свои, правила врача на него не распространяются; наблюдение и откат врач делает в любом случае.

Для Генератора лидмагнитов конкретные пути, маски и недостающие части собраны в частном файле `.private/lead-magnet-integration.md` (вне git) и передаются агенту приложения задачей.
