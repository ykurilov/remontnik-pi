# Quickstart: проверка, что Ремонтник работает

Сценарии проверки готового набора. Подробности форматов — в [contracts/](./contracts/), сущности — в [data-model.md](./data-model.md). Все прогоны — на iMac (`imac-run`).

## Требования

Node 22.19+, pnpm, Docker (только для живой группы), Chromium ставит Playwright.

## 1. Быстрые проверки

```bash
pnpm install
pnpm verify          # сборка → тесты → типы → check-pins → check-public → check-history
```

Ожидаемо: всё зелёное; `check-pins` подтверждает точные версии pi-durable и pi-ai; `check-public` и `gitleaks` находят 0 секретов и адресов; `check-history` подтверждает, что `.private/` не была ни в одном коммите и `gitleaks` чист по всей истории (`pnpm check-history --trees` дополнительно гонит `check-public` по дереву каждого коммита).

## 2. Весь цикл на «Пациенте» без Docker и без сети

```bash
pnpm exec vitest run apps/patient/test/cycle   # из корня набора: пакеты берутся из исходников по корневому vitest.config.ts
```

Подставная модель, выкатка на папках. Каждый сценарий — своя временная папка:

| Сценарий | Заложено | Ожидается |
|---|---|---|
| crash | падение процесса | 1 сообщение Telegram (подставной сервер), случай у врача, ветка с правкой и тестом, выкатка, метка, `healthy` |
| repeat | 50 одинаковых падений | 1 случай со счётчиком 50, 1 сообщение |
| money | ошибка в «оплате» | правка есть, выкатки нет, отчёт `needs_human` |
| test-edit | модель правит существующий тест | выкатки нет, причина `existing_test_changed` |
| worse | правка учащает ошибки | выкатка → откат за < 1 мин, `rolled_back`, повтор отпечатка → только отчёт |
| loop | правка каждый раз хуже | после лимита — `needs_human`, выкаток больше нет |
| stop | стоп-кран включён | отчёт `fix_ready`, выкатки нет |
| budget | потолок расходов = 0.01 | `budget_reached`, случай отложен |
| no-git | удалённый репозиторий недоступен в момент отката | откат из сохранённой сборки |
| paseo | режим «сначала Paseo», подставной мост, агент выкатил хуже | случай передан, врач модель не запускал, откат врачом, отчёт агенту |
| paseo-down | режим «сначала Paseo», мост выключен | врач лечит сам, отчёт «Paseo недоступен» |
| paseo-silent | агент взял случай и замолчал | после срока отмена, `reclaimed`, врач лечит сам, правит один |

## 3. Падения врача

```bash
pnpm --filter @ykurilov/remontnik-doctor test:crash
```

Врач убивается на каждой фазе (`REMONTNIK_TEST_CRASH_AT`), затем запускается снова. Ожидаемо: каждый случай доведён до конца, выкаток ровно одна или ноль, приложение `healthy`.

## 4. Браузер

```bash
pnpm --filter @ykurilov/remontnik-browser test
```

Ожидаемо: вход по сохранённому входу проходит; пароль не найден ни в одном снимке, снимке экрана (после кнопки «глаз» и смены типа поля), ответе и журнале; `pay/delete/publish/send` отклонены; переход на чужой сайт отклонён; изменяющий запрос вне белого списка заблокирован; страница с капчей → `needs_human`; при выключенной службе цикл «Пациента» проходит с пометкой «без проверки в браузере». Живой экран: без ключа владельца, с ключом врача и не с адреса частной сети — отказ; владелец взял управление — команды врача отклонены, клик владельца доходит до страницы; кадров нет в ответах врачу и журналах.

## 5. Сторож и разговоры

```bash
pnpm --filter @ykurilov/remontnik-watch test          # подставная модель
pnpm --filter @ykurilov/remontnik-watch test:live     # настоящий DeepSeek, размеченный выдуманный набор
pnpm --filter @ykurilov/remontnik-watch bench         # горячий путь: ошибка, ответ модели, конец разговора — не больше 1 мс на событие
```

Ожидаемо (живая): найдено ≥ 80% плохих ответов, ложных отметок ≤ 10%; при отказе основного пути — ответ через запасной.

## 6. Живая группа целиком

```bash
pnpm test:live
```

Docker-сборка врача, браузера и верстака; «Пациент» в контейнерах; настоящий DeepSeek. Ожидаемо: случай `crash` проходит от сбоя до `healed`, отчёты в подставном Telegram и в очереди Paseo (`remontnik-doctor reports pull`).

## 7. Подключение по инструкции

Свежий агент получает только `docs/getting-started.md` и подключает набор к копии «Пациента». Ожидаемо: `remontnik-doctor check-config` зелёный, случай `crash` проходит весь цикл.
