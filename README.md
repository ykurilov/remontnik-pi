# Ремонтник Pi

Агент, который сам чинит приложение. Сторож замечает падения и странные ответы бота. Врач находит причину, правит в отдельной ветке, проверяет тестами и eval, выкатывает только при зелёных проверках и сам откатывает при ухудшении. Каждая правка сохраняется в git, прежняя версия всегда остаётся под рукой.

Работает на сервере рядом с приложением, без Paseo. Построен на [@earendil-works/pi-durable](https://github.com/earendil-works/pi/tree/main/packages/durable).

Подключается к приложению как набор пакетов `@ykurilov/remontnik-*`.

## Разработка

Нужны Node 22.19+ и pnpm. `pnpm install`, затем `pnpm verify` — тесты, типы, сборка, проверка точных версий и проверка открытости (нет ключей, настоящих адресов и доменов).
