# Ремонтник Pi

Агент, который сам чинит приложение: сторож замечает падения и странные ответы бота, врач находит причину, правит в ветке, проверяет тестами и eval, выкатывает только при зелёных проверках и откатывает при ухудшении. Работает на сервере рядом с приложением, без Paseo. Построен на [@earendil-works/pi-durable](https://github.com/earendil-works/pi/tree/main/packages/durable).

Подключается к любому приложению Юрия; первое — «Генератор лидмагнитов».
