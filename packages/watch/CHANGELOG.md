## 0.1.5

### Patch Changes

- 8ee6ffb: - **Очередь сторожа после перезапуска процесса в том же контейнере.** Раньше Docker перезапускал упавший процесс, тот снова получал номер 1, и сторож принимал замок прошлой жизни за живой: писал «уже открыта другим живым экземпляром» и заводил новый файл `outbox-<имя>.1-<метка>.jsonl` на каждый перезапуск. Теперь в замке записано и время запуска процесса (`/proc` на Linux, `ps` на остальных системах). Замок с нашим номером, но от другого запуска — от прошлой жизни: процесс снова пишет в основной файл `outbox-<имя>.jsonl`. Так же после пересоздания контейнера с тем же томом. Номер из замка достался другому живому процессу — замок тоже свободен. Два живых процесса с одним `processName` на одной машине и второе открытие очереди в том же процессе по-прежнему пишут в разные файлы.
  - **`watch.wrapModelCatalog` и поставщики Agent Chat SDK.** Обёртка падала с `'get' on proxy: property 'connect' is a read-only and non-configurable data property…`: SDK задаёт `connect` у поставщика неизменяемым свойством. Теперь обёртка работает с неизменяемыми и замороженными каталогами, поставщиками и моделями, включая `doGenerate` и `doStream`. Ошибки моделей по-прежнему становятся случаями `model_error`, для приложения каталог ведёт себя как раньше: те же поля, `connect` по-прежнему неперечисляемый. Поставщик, которого вернул `connect()` обёрнутого поставщика (и `extendCatalog` с `connectProviders`), тоже под присмотром: ошибки его моделей ловятся. Каталог, обёрнутый дважды, о сбое сообщает один раз.
  
  ### Как обновить приложение
  
  1. Поднять `@ykurilov/remontnik-watch` и `@ykurilov/remontnik-core` до новой версии точными версиями, пересобрать и перезапустить приложение.
  2. Уже накопленные файлы `outbox-<имя>.<pid>-<метка>.jsonl` и их замки трогать не нужно. При первом запуске новой версии процесс снова становится хозяином основного файла, переносит из этих файлов недоставленные случаи в основной файл и удаляет их. Случаи уходят врачу, как обычно.
  3. Проверить через минуту после запуска в папке очереди сторожа: для каждого `processName` остались только `outbox-<имя>.jsonl` и `outbox-<имя>.lock`, в журнале процесса нет «уже открыта другим живым экземпляром».
  
  Если `wrapModelCatalog` раньше не ставили из-за этой ошибки — теперь можно: передать в SDK `watch.wrapModelCatalog(catalog)` вместо самого каталога.

## 0.1.0

### Minor Changes

- f0c536c: Первый выпуск набора самолечения приложений.
  
  - `core`: общие части набора и настройка `remontnik.config.ts` (`defineRemontnikConfig`).
  - `watch`: сторож внутри приложения — ловит падения, ошибки модели и инструментов, плохие ответы бота; шлёт случаи врачу и тревоги в Telegram.
  - `doctor`: врач на сервере — находит причину, правит в отдельной ветке, проверяет тестами и eval, выкатывает при зелёных проверках, следит и сам откатывает; переживает падения; команда `check-config`.
  - `browser`: по желанию — браузер врача для воспроизведения ошибок и проверки страниц.
  - `paseo-bridge`: по желанию — режим «сначала Paseo»: случай сперва уходит агенту проекта, врач берёт его сам, только если агент недоступен.
